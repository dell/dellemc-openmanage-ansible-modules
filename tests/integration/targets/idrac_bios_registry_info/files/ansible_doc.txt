
  Query the iDRAC Redfish BIOS Attribute Registry endpoint to retrieve
  complete BIOS attribute metadata.
  Validate proposed BIOS configurations against the registry with
  actionable error messages.
  Filter attributes by name pattern, OEM/standard classification, and
  category.

[1mOPTIONS[0m (red indicates it is required):

   attribute_name  Pattern to filter BIOS attributes by name (supports
                   glob patterns).
        default: null
        type: str

   attribute_source  Filter attributes by source type.
        choices: [all, oem, standard]
        default: all
        type: str

   attributes  Dictionary of attribute names and proposed values to
               validate.
        default: null
        type: dict

   ca_path  The Privacy Enhanced Mail (PEM) file that contains a CA
            certificate to be used for the validation.
        default: null
        type: path

   category  Filter attributes by category (e.g., 'Processor',
             'Memory', 'Security').
        default: null
        type: str

   force_refresh  Force refresh of BIOS attribute registry from iDRAC,
                  bypassing cache.
        default: false
        type: bool

   [1midrac_ip[0m  iDRAC IP Address.
        type: str

   [1midrac_password[0m  iDRAC user password.
                   If the password is not provided, then the
                   environment variable `IDRAC_PASSWORD' is used.
                   Example: export IDRAC_PASSWORD=password
        aliases: [idrac_pwd]
        type: str

   idrac_port  iDRAC port.
        default: 443
        type: int

   [1midrac_user[0m  iDRAC username.
               If the username is not provided, then the environment
               variable `IDRAC_USERNAME' is used.
               Example: export IDRAC_USERNAME=username
        type: str

   timeout  The socket level timeout in seconds.
        default: 30
        type: int

   validate  Validate proposed BIOS configuration against the
             registry.
        default: false
        type: bool

   validate_certs  If `false', the SSL certificates will not be
                   validated.
                   Configure `false' only on personally controlled
                   sites where self-signed certificates are used.
                   Prior to collection version `5.0.0', the
                   [4mvalidate_certs[0m is `false' by default.
        default: true
        type: bool

[1mNOTES:[0m
      * Run this module from a system that has direct access to
        Dell iDRAC.
      * This module supports both IPv4 and IPv6 address for
        [4midrac_ip[0m.
      * Minimum firmware requirement: iDRAC9 >= 7.10.90.00 or
        iDRAC10 >= 1.20.50.50.

[1mREQUIREMENTS:[0m  python >= 3.9.6


[1mAUTHOR[0m: Sapana Gupta(@sapana05)

[1mEXAMPLES:[0m
---
- name: Query all BIOS attributes
  dellemc.openmanage.idrac_bios_registry_info:
    idrac_ip: "192.168.0.1"
    idrac_user: "user_name"
    idrac_password: "user_password"
    ca_path: "/path/to/ca_cert.pem"

- name: Query BIOS attributes with filtering
  dellemc.openmanage.idrac_bios_registry_info:
    idrac_ip: "192.168.0.1"
    idrac_user: "user_name"
    idrac_password: "user_password"
    attribute_name: "Proc*"
    attribute_source: "oem"
    category: "Processor"

- name: Validate BIOS configuration
  dellemc.openmanage.idrac_bios_registry_info:
    idrac_ip: "192.168.0.1"
    idrac_user: "user_name"
    idrac_password: "user_password"
    validate: true
    attributes:
      ProcVirtualization: "Enabled"
      MemTest: "Disabled"
